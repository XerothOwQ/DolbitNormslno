# Шакалилка

Видео-ухудшатор для телефона: PWA на HTML/JS + ffmpeg.wasm.

Открыть: https://xerothowq.github.io/DolbitNormslno/

- 11 видеокодеков (H.264, VP8, MPEG-4, MPEG-2, MPEG-1, H.263, FLV, WMV, MJPEG, Cinepak, MS Video 1)
- 7 аудиокодеков, все параметры видео/аудио, эффекты, 12 пресетов
- Стиль: старый терминал, оранжевый фосфор. Шрифт VCR OSD Mono (fonts/vcr.ttf).

ffmpeg.wasm (lib/) распространяется по своим лицензиям (MIT для обёртки, GPL для ядра ffmpeg с x264).
